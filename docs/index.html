Quick start

  1. Wire it up: Wiring.
  2. Upload firmware/arm/arm.ino with the 5 V supply unplugged.
  3. Move the arm by hand to roughly home, then plug in the 5 V supply.
  4. Plug in the controller, then run cd laptop and python arm.py. The debug dashboard opens in your browser.
  5. Drive with the sticks. Press A to flip and B to stop.
